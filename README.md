# Stock Portfolio Tracker

This is my Python-based stock portfolio tracker that uses Flask, yfinance, and pandas.

## Features
- Add/remove stocks from portfolio
- Show current stock prices & portfolio value
- Calculate profit/loss
- Display stock & portfolio history with charts
- Export portfolio data to CSV

## Tech Stack
- Python
- Flask
- yfinance
- pandas
- matplotlib/plotly
- SQLite

## How to Run
1. Clone repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run Flask app: `python backend/app.py`
